Download **RgbControl-Setup-1.1.0.exe** below and run it to install or upgrade. Existing settings are retained; no separate .NET installation is required.

- Added independent motherboard ARGB-header settings for lighting such as the NZXT Kraken Core 360 RGB and its included fans.
- Added opt-in direct lighting control for Sapphire NITRO+ RX 9070 XT and PowerColor Red Devil RX 9070 XT, with explicit motherboard ARGB-cable sync options.
- Added experimental Gigabyte B650 AORUS Elite AX support, targeting rev. 1.2.
- Corrected Sapphire effect switching to write the effect before refreshing the color, with settling delays and register verification.
- Improved startup configuration watching and coordination between lighting updates and sleep/shutdown.

ASUS Aura and ENE RAM remain the established support paths. New GPU and Gigabyte support is experimental: Sapphire register reads/writes have been verified, but visible effect switching and power-cycle validation remain incomplete; PowerColor and Gigabyte require hardware validation. GPU management is disabled by default. See [hardware support](https://github.com/Romoslayer/rgb-control/blob/v1.1.0/docs/hardware-support.md) for exact device IDs and limitations.

The installer is unsigned. An adjacent SHA256 file is provided for download verification.
